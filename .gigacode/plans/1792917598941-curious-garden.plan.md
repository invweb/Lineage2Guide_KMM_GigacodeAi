# План: Исправление Desktop приложения

## Проблема
1. **Пустое окно** — показывается только строка поиска, данные не загружаются
2. **Нельзя вставить текст** в строку поиска

## Причины

### 1. Пустое окно
- `ItemsViewModel.uiState` имеет начальное значение `ItemsUiState(isLoading = true)`
- При ошибке загрузки (сервер не запущен) исключение ловится в `catch` и только логируется
- `allItems` никогда не обновляется → `filteredItems` не получает новых данных
- `uiState` навсегда остаётся в `isLoading = true` → показывается `LoadingScreen`

### 2. Нельзя вставить текст
- `SearchBar` использует `.focusable()` — deprecated модификатор, ломает paste на Desktop

---

## Решение

### Шаг 1: Добавить обработку ошибок в ViewModel

**Файл:** `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/items/ItemsViewModel.kt`

Добавить `UiState` с корректной обработкой ошибок:
- При ошибке устанавливать `uiState.error` вместо silent catch
- Убрать `isLoading = true` из initial state

### Шаг 2: Исправить SearchBar для Desktop

**Файл:** `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/common/components/SearchBar.kt`

Удалить `.focusable()` — он не нужен и ломает paste на Desktop.

### Шаг 3: Добавить логирование для отладки

**Файл:** `desktop/src/desktopMain/kotlin/com/zx_tole/lineage2_guide/DesktopApp.kt`

Добавить логирование при инициализации Koin и при загрузке данных.

### Шаг 4: Проверить сервер

Убедиться что сервер запущен:
```bash
cd server && ./gradlew run
```

## Верификация

1. Запустить сервер: `./gradlew :server:run`
2. Запустить Desktop: `./gradlew :desktop:runDesktop`
3. Проверить что:
   - Отображаются карточки предметов (Items)
   - Можно вставлять текст в поиск (Cmd+V)
   - При остановке сервера показывается экран ошибки с кнопкой "Try Again"
   - Поиск фильтрует элементы
