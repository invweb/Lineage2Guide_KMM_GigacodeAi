# UI Improvement Plan — Lineage 2 Guide iOS/Android

## Цель
Сделать интерфейс визуально привлекательным: заменить скучные иконки на реальные, добавить цветовую кодировку по редкости, убрать непонятные бейджи.

## Проблема
- Все предметы отображаются с красной звёздкой ⭐ (без разницы, меч это, щит или зелье)
- Бейдж "COM" непонятный и не несёт ценности
- Нет цветовой кодировки по редкости (Common, Uncommon, Rare, Epic, Legendary)
- Interface функциональный, но скучный

## План улучшений

### Фаза 1: Быстрые (1-2 часа)

#### 1. Заменить звёзды на реальные иконки из API
- **Файл:** `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/items/ItemsScreen.kt`
- Использовать `iconUrl` из API (`http://localhost:8080/api/v1/icons/items/{id}`)
- Загрузить через Coil `AsyncImage` с иконкой по умолчанию
- Аналогично для Skills, NPCs, Quests, Classes

#### 2. Цветовая кодировка по редкости
- Common → серый
- Uncommon → зелёный
- Rare → синий
- Epic → фиолетовый
- Legendary → оранжевый
- **Файлы:**
  - `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/items/ItemsScreen.kt`
  - `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/skills/SkillsScreen.kt`
  - `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/npcs/NpcsScreen.kt`
  - `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/quests/QuestsScreen.kt`
  - `shared/src/commonMain/kotlin/com/zx_tole/lineage2_guide/ui/classes/ClassesScreen.kt`

#### 3. Убрать "COM" бейдж, заменить на цветной редкости
- Удалить `rarity` бейдж
- Добавить цветной индикатор слева от карточки (полоска)

### Фаза 2: Средние (3-5 часов)

#### 4. Detail-экраны
- Красивое отображение характеристик с иконками
- ⚔️ atk, 🛡️ def, ⚡ speed, 💫 crit
- Скриншоты для README

#### 5. Улучшить AppBar
- Добавить иконку/логотип вместо текста "Lineage 2"
- Улучшить поиск
