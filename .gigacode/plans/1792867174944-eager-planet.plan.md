# План: iOS Compose Multiplatform для Lineage 2 Guide

## Цель
Сделать полностью рабочую iOS-версию приложения через Compose Multiplatform. Все 5 категорий (Items, Quests, Skills, Classes, NPCs) — list + detail экраны.

## Архитектурные решения
- **Compose Multiplatform** для всего UI на iOS
- **API-only** для iOS (без SQLDelight/Room)
- **Koin 4.0.0** для DI (koin-core, без Android-зависимостей)
- **Кастомная tab-навигация** (не androidx.navigation)
- **baseUrl** захардкоден в iOS-инициализации

---

## Фаза 1: Shared Module — Убрать SQLDelight, добавить Compose для iOS

### 1.1 Удалить SQLDelight зависимости
**Файл:** `shared/build.gradle.kts`
- Удалить `sqldelight` плагин
- Удалить зависимости: `runtime`, `android-driver`, `native-driver`, `jdbc-driver`

### 1.2 Исправить DriverFactory
- `commonMain`: `expect fun createDriver(): Any?`
- `iosMain`: `actual fun createDriver(): Any? { return null }`
- `androidMain`: оставить как есть (Android использует Room)

### 1.3 Добавить Compose for iOS зависимости
**Файл:** `shared/build.gradle.kts`
```kotlin
// В commonMain.dependencies:
implementation("org.jetbrains.compose.ui:ui-ios:1.7.0")
implementation("io.insert-koin:koin-compose:4.0.0")
```

## Фаза 5: Создать Xcode проект

### 5.1 Собрать shared framework
```bash
./gradlew :shared:clean :shared:assembleFrameworkIosSimulatorArm64
```

### 5.2 Создать Xcode проект
- Платформа: iOS, шаблон: App (SwiftUI)
- Deployment Target: iOS 15.0+
- Bundle ID: `com.zx_tole.lineage2_guide`

### 5.3 Настроить Build Phases
- **Link Binary With Libraries:** добавить `shared.framework` (Do Not Embed)
- **Run Script:** копировать framework из `shared/build/bin/`
- **Header Search Paths:** `$(PROJECT_DIR)/../shared/build/bin/iosSimulatorArm64/releaseFramework` (recursive)
- **Framework Search Paths:** тот же путь (recursive)

### 5.4 Добавить Swift файлы в target
- `iosApp.swift`
- `ComposeViewController.swift`
- `ComposeView.swift`
